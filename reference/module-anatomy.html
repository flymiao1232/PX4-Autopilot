参考 · PX4 模块骨架速查

打印友好 · 写新模块时从这里抄骨架 · 随课程更新

三个文件起步,一个符号启用。抄完骨架再填业务逻辑。

一、目录与三件套

src/examples/<my_module>/          # 名字全小写;CONFIG_EXAMPLES_<MY_MODULE> 要能映射到它
├── <my_module>.h                 # 类声明(继承 ModuleBase)
├── <my_module>.cpp               # 实现 + <my_module>_main
├── CMakeLists.txt               # px4_add_module
└── Kconfig                      # menuconfig EXAMPLES_<MY_MODULE>

板级启用(在 boards/px4/sitl/default.px4board 或目标板子的 px4board):

CONFIG_EXAMPLES_<MY_MODULE>=y

二、CMakeLists.txt 最小模板

px4_add_module(
	MODULE examples__<my_module>   # 父目录前缀__模块名
	MAIN <my_module>               # shell 命令名 = 入口函数前缀
	STACK_MAIN 2000                # 主线程栈大小(字节)
	SRCS
		<my_module>.cpp
	DEPENDS
	)

三、Kconfig 最小模板

menuconfig EXAMPLES_<MY_MODULE>
	bool "<my_module>"
	default n
	---help---
		Enable support for <my_module>

四、C++ 骨架(task 版)

头文件:

#pragma once

#include <px4_platform_common/module.h>

extern "C" __EXPORT int <my_module>_main(int argc, char *argv[]);

class <MyModule> : public ModuleBase<<MyModule>>
{
public:
	<MyModule>() = default;
	~<MyModule>() override = default;

	static int task_spawn(int argc, char *argv[]);
	static <MyModule> *instantiate(int argc, char *argv[]);
	static int custom_command(int argc, char *argv[]);
	static int print_usage(const char *reason = nullptr);

	void run() override;
	int print_status() override;
};

实现文件要点(完整可运行示例见第 4 课 my_first_app 与官方模板 src/templates/template_module/):

int <MyModule>::task_spawn(int argc, char *argv[])
{
	_task_id = px4_task_spawn_cmd("<my_module>",
				      SCHED_DEFAULT,          // 调度策略
				      SCHED_PRIORITY_DEFAULT, // 优先级
				      2000,                   // 栈大小
				      (px4_main_t)&run_trampoline,
				      (char *const *)argv);
	if (_task_id < 0) { _task_id = -1; return -errno; }
	return 0;
}

void <MyModule>::run()
{
	// 订阅
	int sub_fd = orb_subscribe(ORB_ID(sensor_combined));
	px4_pollfd_struct_t fds[1] = { { .fd = sub_fd, .events = POLLIN } };

	while (!should_exit()) {              // ← stop 命令的开关
		px4_poll(fds, 1, 1000);
		if (fds[0].revents & POLLIN) {
			struct sensor_combined_s raw;
			orb_copy(ORB_ID(sensor_combined), sub_fd, &raw);
			// …业务逻辑…
		}
	}
	orb_unsubscribe(sub_fd);
}

int <my_module>_main(int argc, char *argv[])
{
	return <MyModule>::main(argc, argv);   // start/stop/status 由 ModuleBase 提供
}

五、Work queue 版差异(轻量模块)

不独占线程,继承 px4_platform_common/px4_work_queue/ScheduledWorkItem,注册后按周期被共享队列唤醒。参考 src/examples/work_item/:

class <MyModule> : public ModuleBase<<MyModule>>, public ScheduledWorkItem
{
	…
	void Run() override;  // 注意大写 R,每次被唤醒执行一次
};

// 启动时:
ScheduleOnInterval(1000000_us);  // 每 1 秒唤醒一次
// 停止时:
ScheduleClear();

六、shell 命令一览

命令效果落到哪个函数
<module>(无参数)打印用法print_usage()
<module> start后台启动task_spawn() → instantiate() → run()
<module> stop优雅停止should_exit() 变 true
<module> status运行状态print_status()
uorb top确认模块在发布/订阅—

七、常见坑

  • Couldn't find path:CONFIG 符号名与目录名不一致(全小写对照)。
  • start 后没反应:先看 <module> status,再用 uorb top 确认订阅的 topic 有数据;run() 里 poll 超时太短会空转,太长 stop 响应慢。
  • stop 后还在打印:run() 循环里用了阻塞 IO 且没有检查 should_exit()。
  • 栈溢出:局部大数组/深递归 → 调大 STACK_MAIN,或 SITL 下看 dmesg。
