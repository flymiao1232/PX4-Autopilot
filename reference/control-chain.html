一条链,五个环节

┌─ 1 期望生成 ─────────────────────────────────────────────┐
│  commander / navigator(任务)· manual_control(手动摇杆)   │
│      ↓ 发布                                                │
│  vehicle_attitude_setpoint      姿态期望(四元数+推力)      │
└───────────────────────────────────────────────────────────┘
                      ↓
┌─ 2 姿态环(外环)· mc_att_control ────────────────────────┐
│  订阅: vehicle_attitude_setpoint + vehicle_attitude        │
│  发布: vehicle_rates_setpoint   角速度期望      [P 控制]   │
│  源码: mc_att_control.hpp:113(回调) :115(发布)            │
└───────────────────────────────────────────────────────────┘
                      ↓
┌─ 3 角速度环(内环)· mc_rate_control ─────────────────────┐
│  订阅: vehicle_rates_setpoint + vehicle_angular_velocity   │
│  发布: vehicle_thrust_setpoint + vehicle_torque_setpoint   │
│  源码: mc_rate_control/MulticopterRateControl.cpp          │
│        :126(回调入口) :260/:264(发布)  [PID,最快]          │
└───────────────────────────────────────────────────────────┘
                      ↓
┌─ 4 控制分配 · control_allocator ────────────────────────┐
│  订阅: vehicle_thrust_setpoint + vehicle_torque_setpoint   │
│  发布: actuator_motors(每电机 0~1)                        │
│  配置: CA_ROTOR*(电机位置/方向,见机架文件)                 │
│  源码: ControlAllocator.hpp:178-187                        │
└───────────────────────────────────────────────────────────┘
                      ↓
┌─ 5 执行与反馈 ───────────────────────────────────────────┐
│  pwm_out_sim → gz 电机 → 机体运动 → IMU →                  │
│  vehicle_angular_velocity / sensor_combined →(回到环 2/3)  │
└───────────────────────────────────────────────────────────┘

三个易错点(对照老资料时)

错误认知v1.17 真相出处
内环输出是 actuator_controls_0是 vehicle_thrust_setpoint + vehicle_torque_setpoint 两个 topicMulticopterRateControl.hpp:110-111
控制频率在配置文件里由 SubscriptionCallbackWorkItem 以上游数据到达唤醒,频率靠 uorb top 实测MulticopterRateControl.cpp:67,126
电机指令由控制器直接算控制器只算推力+力矩,电机分配是 control_allocator 的事ControlAllocator.hpp:178-187
