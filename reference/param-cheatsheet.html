二、params.c 最小模板

/**
 * 参数的一句话说明
 *
 * 更详细的多行说明(给地面站看)
 *
 * @boolean            # 或 @min / @max / @unit / @group 模块名
 * @group My Module
 */
PARAM_DEFINE_INT32(MOD_PREFIX_NAME, 1);   # 或 PARAM_DEFINE_FLOAT(...)
  • 参数名 ≤ 16 字符(px4params/srcparser.py:370),全大写 + 模块前缀,如 LR5_PUB_EN、LND_FLIGHT_T_HI、UXRCE_DDS_PRT
  • 宏第二个参数 = 默认值,也是 param reset 回到的值
  • 参考实例:src/modules/zenoh/zenoh_params.c(最小)、src/modules/land_detector/land_detector_params.c(全注解)

三、常见症状 → 对策

症状最可能原因对策
param_find 返回 PARAM_INVALID新 params.c 后 cmake 没重配,GLOB 未刷新touch src/lib/parameters/CMakeLists.txt && make;不行则 make clean
param show 找不到参数同上;或文件名不匹配 *params.c检查文件名后缀;重配
param set 后模块行为不变值在 start 时只读了一次循环内每轮 param_get,或订阅 parameter_update
param set 重启后丢失没保存param save(SITL 存在 build 目录的虚拟存储)

四、参数 vs topic(判别法)

参数 = 配置:慢变、有默认值、可持久化,回答"模块应该怎么工作"。
topic = 数据:快变、last-value-cached,回答"系统正在发生什么"。
拿不准就问:改了之后需要断电保存吗?需要 → 参数。
