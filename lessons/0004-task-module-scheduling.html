第 4 课 · 正式模块与调度

Mission:能独立改 PX4 代码 2026-11-01 · 约 30 分钟 · 路线:课程地图 · 上一课:第 3 课 · 骨架速查:模块解剖

到目前为止,你的 my_first_app 是个"一次性命令":跑完就退出。但 PX4 里真正干活的模块(ekf2、mc_att_control……)都是常驻后台、可启动、可停止、可查询状态的。这一课就把你的小工具升级成这种"正经模块",对应官方 Application/Module Template。仓库里的模板源码是 src/templates/template_module/——本课代码就是它的简化版。

一、一个 PX4 模块的"活法"

模块有三种存在方式,按重量级递增:

方式特点适用例子
一次性命令跑完 main 就退出工具、测试第 2 课的 my_first_app(旧版)
后台任务 (task)独立线程,start/stop/status大多数模块ekf2、template_module
工作队列项 (work item)共享队列线程,按周期被唤醒轻量、周期任务load_mon、battery_status、work_item 示例

实现上,它们都建立在同一个基类上:ModuleBase<T>(px4_platform_common/module.h)。你只需填五个"槽",命令行三件套自动获得:

你实现的职责
task_spawn()创建任务线程(px4_task_spawn_cmd),把 run() 挂上去
instantiate()解析参数,new 出模块对象
run()主循环,用 while (!should_exit()) 包住,stop 时被优雅打断
custom_command()你自己的子命令(本课用不到)
print_usage() / print_status()帮助文本 / status 时打印运行状态
pxh> my_first_app          # 无参数 → ModuleBase 打印用法(print_usage)
pxh> my_first_app start    # task_spawn → run() 在后台线程跑起来
pxh> my_first_app status   # print_status()
pxh> my_first_app stop     # should_exit() 变 true,run() 退出

二、动手:重写 my_first_app 为 C++ 模块

⚠️ 语言切换提醒:work queue 和 ModuleBase 都是 C++ 的,所以模块改用 C++ 编写(文件后缀 .cpp)。语法别担心——本课代码量很小,你只需要"照抄 + 看懂结构",C++ 细节遇到再学。

  1. 删除旧 C 文件,新建头文件 src/examples/my_first_app/my_first_app.h:

    rm src/examples/my_first_app/my_first_app.c
    #pragma once

#include <px4_platform_common/module.h>

extern "C" __EXPORT int my_first_app_main(int argc, char *argv[]);

class MyFirstApp : public ModuleBase<MyFirstApp>
{
public:
	MyFirstApp() = default;
	~MyFirstApp() override = default;

	/** @see ModuleBase */
	static int task_spawn(int argc, char *argv[]);
	static MyFirstApp *instantiate(int argc, char *argv[]);
	static int custom_command(int argc, char *argv[]);
	static int print_usage(const char *reason = nullptr);

	void run() override;
	int print_status() override;
};

    注意:类继承 ModuleBase<MyFirstApp>——尖括号里是自己,这是 C++ 的 CRTP 技巧,ModuleBase 靠它找到你的静态方法。

  2. 新建 src/examples/my_first_app/my_first_app.cpp:

    #include "my_first_app.h"

#include <px4_platform_common/log.h>
#include <px4_platform_common/posix.h>

#include <poll.h>
#include <errno.h>

#include <uORB/uORB.h>
#include <uORB/topics/sensor_combined.h>

int MyFirstApp::print_status()
{
	PX4_INFO("Running");
	return 0;
}

int MyFirstApp::custom_command(int argc, char *argv[])
{
	return print_usage("unknown command");
}

int MyFirstApp::task_spawn(int argc, char *argv[])
{
	_task_id = px4_task_spawn_cmd("my_first_app",
				      SCHED_DEFAULT,
				      SCHED_PRIORITY_DEFAULT,
				      2000,
				      (px4_main_t)&run_trampoline,
				      (char *const *)argv);

	if (_task_id < 0) {
		_task_id = -1;
		return -errno;
	}

	return 0;
}

MyFirstApp *MyFirstApp::instantiate(int argc, char *argv[])
{
	MyFirstApp *instance = new MyFirstApp();

	if (instance == nullptr) {
		PX4_ERR("alloc failed");
	}

	return instance;
}

void MyFirstApp::run()
{
	int sensor_sub_fd = orb_subscribe(ORB_ID(sensor_combined));
	orb_set_interval(sensor_sub_fd, 1000);  // 限制到 1 Hz

	px4_pollfd_struct_t fds[1];
	fds[0].fd = sensor_sub_fd;
	fds[0].events = POLLIN;

	while (!should_exit()) {          // stop 命令会把它变为 true
		px4_poll(fds, 1, 1000);

		if (fds[0].revents & POLLIN) {
			struct sensor_combined_s raw;
			orb_copy(ORB_ID(sensor_combined), sensor_sub_fd, &raw);
			PX4_INFO("Accel:\t%8.4f\t%8.4f\t%8.4f",
				 (double)raw.accelerometer_m_s2[0],
				 (double)raw.accelerometer_m_s2[1],
				 (double)raw.accelerometer_m_s2[2]);
		}
	}

	orb_unsubscribe(sensor_sub_fd);
}

int MyFirstApp::print_usage(const char *reason)
{
	if (reason) {
		PX4_WARN("%s\n", reason);
	}

	PRINT_MODULE_DESCRIPTION(
		R"DESCR_STR(
### Description
Lesson example: subscribe sensor_combined, print accel at 1 Hz.

### Examples
CLI usage example:
$ my_first_app start

)DESCR_STR");

	PRINT_MODULE_USAGE_NAME("my_first_app", "example");
	PRINT_MODULE_USAGE_COMMAND("start");
	PRINT_MODULE_USAGE_DEFAULT_COMMANDS();

	return 0;
}

int my_first_app_main(int argc, char *argv[])
{
	return MyFirstApp::main(argc, argv);   // start/stop/status 都在这里面
}

  3. 更新 src/examples/my_first_app/CMakeLists.txt,把源文件换成 .cpp:

    px4_add_module(
	MODULE examples__my_first_app
	MAIN my_first_app
	STACK_MAIN 2000
	SRCS
		my_first_app.cpp
	DEPENDS
	)

  4. 编译:

    make px4_sitl_default

  5. 运行——重点体验三件套(接 Gazebo 数据更直观,HEADLESS=1 make px4_sitl gz_x500):

    pxh> my_first_app          # 打印用法
pxh> my_first_app start    # 后台运行,每秒打印一行 Accel
pxh> my_first_app status   # Running
pxh> my_first_app stop     # 打印停止

  6. (对照阅读,5 分钟)打开官方模板 src/templates/template_module/template_module.{h,cpp},找找你刚写的五个"槽"在哪。模板比你多出来的部分:px4_getopt 命令行参数解析、ModuleParams 参数接入——后者就是第 6 课的内容。

✅ 本课的胜利:你的模块现在有了 PX4 模块的"标准身法":可启动、可停止、可查询,主循环能被优雅打断。至此,你已经掌握了在 PX4 里"像原住民一样"写代码的全部基本套路——模块骨架速查表 已备好,以后写新模块从它出发。

三、课后探索(可选)

第三种"活法"——work queue:读 src/examples/work_item/,它继承 ScheduledWorkItem,不独占线程,而是注册到共享工作队列按周期唤醒(ScheduleOnInterval)。这是 PX4 轻量模块的主流做法(load_mon、battery_status 都是)。看懂它和本课 task 版的差异,你就集齐了三种活法。
